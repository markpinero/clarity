# Repository Guidelines

## Git commits

- Use Conventional Commits for every commit message, such as `feat:`, `fix:`, `test:`, `docs:`, `refactor:`, `build:`, or `chore:`. Add a scope when it improves clarity.
- Keep commits atomic: each commit should contain one coherent change and its directly related tests or documentation.
- Do not combine unrelated worktree changes in the same commit.
